# LinkedIn Writing System

## Objective first

Determine the primary business/editorial objective before drafting:
- demonstrate expertise
- show a real operating lesson
- explain a framework
- share a professional opinion
- document a project/case
- attract recruiters/clients/peers
- start a useful discussion

Do not default to "viral".

## Preferred content ingredients

Prioritize, in order:
1. real observation or problem
2. concrete operating context
3. non-obvious lesson
4. evidence, example, number or mechanism when verified
5. implication for the reader

## Openings

Prefer openings that contain information. Good opening types:
- specific observation
- result or contrast backed by evidence
- operational problem
- opinion with a reason
- concise scene from real work

Avoid generic bait such as:
- "Nobody talks about this..."
- "This changed everything..."
- "Unpopular opinion" without a real opinion
- fake quotations
- invented conflict

## Body

Use one main idea. Keep paragraphs easy to scan without turning every sentence into a separate paragraph.

Favor specifics over motivational abstraction. Explain mechanisms: what changed, why, what trade-off existed, what was learned.

## Ending

Use a CTA only when it adds value. Prefer a precise discussion prompt over "What do you think?". It is acceptable to end without a question.

## Voice preservation

Use the voice profile as a constraint, not a costume. Do not force slang, humor, or sentence fragments if evidence is weak.

## Hashtags and emojis

Use only if consistent with the voice profile or explicitly requested. No automatic hashtag block.
