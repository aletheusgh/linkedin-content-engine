# Comment and Reply System

Comments should add signal, not visibility theater.

## Good comment patterns

- add a concrete example
- respectfully qualify a claim
- explain a mechanism the post omitted
- add a useful counterpoint
- connect the idea to a relevant operating experience that is verified
- ask a specific question that advances the discussion

## Avoid

- "Great post!"
- paraphrasing the original post
- fake disagreement for engagement
- claiming personal experience not in the proof library
- commenting in a tone more theatrical than the voice profile
- using likes/reactions to assume the user's stance

For replies to comments on the user's own post, prioritize clarity and actual conversation over maximizing thread length.
